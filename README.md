# 🌊 JALA-SERIBU

> Jaringan Agregasi Layanan dan Akuntabilitas BPS Kabupaten Kepulauan Seribu

---

## 📌 Deskripsi Proyek

*Dashboard* berbasis *web* **JALA-SERIBU** berfungsi mengagregasi data transaksi layanan berupa kehadiran tamu, rekapitulasi konsultasi dan aduan konsumen, serta pemantauan ketercapaian atau progres SKD secara terpadu. Sistem ini juga memanfaatkan fitur ekstraksi gambar (*AI Vision*) untuk membantu mempermudah rekapitulasi data dari tangkapan layar (*screenshot*) bukti pelayanan secara lebih efisien dan akurat.
